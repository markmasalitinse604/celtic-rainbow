# Celtic Rainbow Truck & Bus School — лендинг

Статичный сайт на 4 языках: из одного шаблона и словаря собираются
`dist/pl/`, `dist/pt/`, `dist/ru/`, `dist/en/`. Зависимостей нет, нужен только Node 18+.

## Структура

```
truck-bus-theory/
  build.js            сборка; вверху настройки SITE_URL, PHONE и BRAND
  package.json
  src/
    locales.js        ← СЛОВАРЬ: все тексты на 4 языках
    template.html     разметка с ключами {{heroTitle}} и т.п.
    styles.css        стили, цвета в переменных :root
    ride.js           ролик на первом экране, едет вслед за прокруткой
    route.js          логика блока «Твой путь»
    gallery.js        открытие фото галереи на весь экран
    menu.js           меню-панель на телефоне и список языков на десктопе
    assets/
      logo.png        логотип (шапка и подвал)
      favicon.png     иконка вкладки
      teacher.jpg     фото преподавателя (положить самому)
      gallery/        фото для галереи (положить самому)
      ride/           кадры ролика первого экрана (hd, land, port)
  video/              исходники роликов, в сборку не попадают
  dist/               результат сборки, создаётся сам
```

## Первый запуск

1. Заполни свои данные в `src/locales.js`: поля с [квадратными скобками] (`name`, `about`) в каждом языке.
2. В `build.js` впиши контакты: `PHONE` (только цифры, без `+`), `PHONE_DISPLAY` (как номер показать на странице), `FACEBOOK_URL` и `SITE_URL`.
3. Собери: `npm run build` (или `node build.js`).
4. Открой папку `dist` через Live Server.

## Правки

- **Текст** — в `src/locales.js`, во всех четырёх языках. Затем снова `npm run build`.
- **Разметка** — в `src/template.html`. Новый ключ `{{myKey}}` должен быть в каждом языке словаря, иначе сборка остановится с ошибкой.
- **Цвета и размеры** — в `src/styles.css`, палитра в начале файла.
- **Фото преподавателя** — положи `src/assets/teacher.jpg` (или `.png`, `.webp`): оно само встанет в «Обо мне».
- **Галерея** — клади картинки в `src/assets/gallery/`. Порядок — по имени файла, удобно называть `01.jpg`, `02.jpg`… Пока папка пустая, показываются заглушки.
- **Название** — константа `BRAND` в `build.js`.

## Публикация

На Netlify, Vercel или Cloudflare Pages: команда сборки `npm run build`, папка публикации `dist`.
