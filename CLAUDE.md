# Celtic Rainbow Truck & Bus School — лендинг

Рекламный сайт частного преподавателя теории на права категорий C (грузовик) и D (автобус) в Ирландии.
Аудитория — мигранты, в первую очередь поляки и бразильцы. Преподаватель один, ведёт занятия сам,
говорит на польском, португальском, русском и английском. Общаемся с владельцем проекта по-русски.

## Ветки и выкладка

- Netlify выкладывает `main`. Редизайн «дорога» делается в отдельной ветке (локально `journey`,
  на GitHub — `claude/landing-cinematic-redesign-5jbd7q`), в `main` попадает только через pull request.
  В `main` напрямую не пушить и не мержить без решения владельца.

## Стек и сборка

- Чистые HTML + CSS + немного JS, без фреймворков и зависимостей. Нужен только Node 18+.
- `npm run build` (= `node build.js`) собирает главную `dist/<язык>/` и экран выбора `dist/<язык>/choose/`
  для pl, pt, ru, en из шаблонов и одного словаря.
- `dist/index.html` — развилка: машину уже выбирали (`localStorage.vehicle`) — сразу на главную `/<язык>/`,
  иначе на экран выбора `/<язык>/choose/` (язык — см. «Экран выбора»).
- Ко всем своим `.css`/`.js` (и картинкам экрана выбора) в HTML дописывается `?v=<хэш>` (`stampRefs` в `build.js`) —
  после пересборки браузер не берёт старое из кэша.
- Хостинг: Netlify (команда сборки `npm run build`, папка публикации `dist`). В `netlify.toml` кадрам ролика
  (`/assets/ride*/`) задано кэширование на сутки: перенарезанные кадры у вернувшихся посетителей обновятся в течение суток.
- Смотреть локально: собрать и открыть `dist` через Live Server (не через `file://`).

## Структура

- `build.js` — сборка. Вверху настройки: `SITE_URL`, `PHONE` (цифры для wa.me и tel:), `PHONE_DISPLAY`,
  `FACEBOOK_URL` (пусто — ссылка скрыта), `BRAND`, `LANGS`, `DETECT_BROWSER_LANGUAGE`.
  Там же: набор значков `ICONS` (тонкие линейные, `{{icons}}`), общая шапка `renderHeader()` (`{{header}}`),
  нижняя панель `renderDock()` (`{{dock}}`) и блоки главной в `blocks()`.
- `src/template.html` — главная, ключи `{{ключ}}`. Простые ключи — из словаря, составные — из `blocks()`.
- `src/locales.js` — словарь: `module.exports = { pl, pt, ru, en }`, ключи во всех языках одинаковые.
  Сборка падает с понятной ошибкой, если ключа нет в каком-то языке или в словаре нет ключа из шаблона.
  Метки в текстах: `{cat}` — категория (см. «Транспорт»), `{n}` — номер шага; в старых строках плана `{V}` и `{L}`.
- `src/shared/` — общее для экрана выбора и главной, копируется в `dist/shared/`:
  `tokens.css` (палитра и шрифты), `hud.css` (шапка, нижняя панель `.dock`), `hud.js` (список языков и `track()`),
  `sound.js` (`window.SiteSound`: общее состояние звука, фоновая петля главной).
- `src/landing.css` — стили главной. `src/ride.js` — шапка над сценой и «дорога» (ролик + карточки).
  `src/vehicle.js` — транспорт (C / D / оба). `src/plan.js` — «Соберите свой план». `src/gallery.js` — галерея.
- `src/assets/` — `logo.png`, `favicon.png` (только колесо), `og.jpg` (картинка для соцсетей),
  `teacher.jpg` (если положить — встаёт в «Ваш преподаватель», можно .png/.webp),
  `gallery/` (картинки галереи по имени файла; пусто — секции нет совсем),
  `ride/{hd,land,port}` — кадры ролика с фурой, `ride-bus/{hd,land,port}` — кадры автобуса,
  `media/ambient.m4a` — фоновый звук главной.
- `src/choose/` — экран выбора транспорта: шаблон `index.html` → `dist/<язык>/choose/`, остальное → `dist/choose-assets/`.
- `video/` — исходники роликов (ИИ, 10 с, 24 к/с), в сборку не попадают: `truck.mp4` (фура, горизонтальный 3828×2164),
  `vertical.mp4` (фура, вертикальный 2164×3832), `bus.mp4` (автобус, горизонтальный 3832×2164; вертикального нет).
  `assets-src/choose/` — исходные фото экрана выбора, `assets-src/ride-bus/` — скрипт кадров автобуса для телефона.

## Договорённости (важно соблюдать)

- Любой текст меняется во всех четырёх языках сразу.
- Цен на сайте нет вообще: ни цен курса, ни официальных сборов RSA. Убраны намеренно.
- Позиционирование — «курс теории», а не уроки вождения: платно учить вождению в Ирландии может только ADI.
  В подвале дисклеймер «не связан с RSA, NDLS, theorytest.ie». Не имитировать официальные сайты.
- Официальные вопросы RSA не копировать и не переводить (авторские права RSA).
- В Ирландии левостороннее движение: все машины в графике/видео едут по левой полосе.
- Грузовик — это две категории, C и CE: везде, где показана категория грузовика, писать «C, CE» (в текстах,
  шапке, подписях экрана выбора, плане, сообщениях WhatsApp, возрасте, метаописании). Исключение — ответ
  «Нужно менять права из ЕС?»: там «learner permit C или D», потому что на CE сразу подать нельзя (нужны полные права C).
- Доступность: семантические теги, один `h1`, видимый фокус (золотое кольцо), контраст AA, `prefers-reduced-motion`.
- Тексты (бриф клиента: «вау-эффект», посетитель должен загореться профессией водителя): продаём дорогу
  и результат, но честно. Нельзя обещать: «станьте водителем», работу, зарплаты, гарантии, сроки, цифры о деньгах
  или спросе. Не выдумывать факты, отзывы и цифры. Короткие фразы, заголовки — утверждения (вопросы — только в плане).
  Тон: русский — «вы» в тексте, кнопки безличные («Написать в WhatsApp»), заголовки — вежливый императив, «ты» нигде;
  польский — нейтральный императив и «Twój/Twoja», без «Pan/Pani»; португальский (Бразилия) — «você»;
  английский — нейтральный. Термины NDLS, CPC, learner permit, ADI, walkaround, RSA не переводим.

## Шапка (общая, `renderHeader()` + `src/shared/hud.css`)

- ПК: логотип + название слева; справа кнопка категории, язык, звук, WhatsApp (ссылку «Контакты» владелец
  попросил убрать). Уже 1180px прячется слово «Звук», уже 1020px — название.
- Телефон (`max-aspect-ratio: 9/10` или уже 760px; на экране выбора — `max-aspect-ratio: 4/5`, как было):
  только значок, кнопка категории («C, CE», D или «C, CE / D»), язык кодом (PL), круглая кнопка звука;
  WhatsApp и звонок — в нижней панели.
- Кнопка категории (только на главной) ведёт на `/<язык>/choose/` без параметра, доступное имя — `changeVehicle`.
  На экране выбора кнопки категории нет (решение владельца).
- Язык: `<details class="lang-menu">`, закрывается кликом мимо и Esc; `shared/hud.js` записывает

- Аналитика: у всех ссылок WhatsApp `data-track="whatsapp"`; `track()` в `shared/hud.js` вызывает
  `fbq('trackCustom', 'WhatsAppClick')`, только если на странице есть пиксель Facebook (`window.fbq`).
  Сам пиксель не установлен: код пикселя вставлять в `<head>` обоих шаблонов (`src/template.html` — там
  отмечено место, и `src/choose/index.html`).

## Транспорт (`src/vehicle.js`)

- Источник: `?vehicle=truck|bus` (с экрана выбора; запоминается) → `localStorage.vehicle` → «оба»
  (вариант «оба» — когда на главную пришли сразу, минуя экран выбора; ссылку «Пока не знаю» с экрана выбора
  владелец попросил убрать).
- Статичный HTML собран в варианте «оба» (для поисковиков): `{cat}` в словаре → `<span data-cat>C, CE / D</span>`
  (`CAT_BOTH` в `build.js`), скрипт меняет на «C, CE» или D (`CAT` в `vehicle.js`). Строка возраста: C, CE — с 18
  с CPC / с 21 без; D — с 21 / с 24; в «обоих» — обе строки (`data-age="C"` / `"D"`).
  План и сообщения WhatsApp (`waCat`) — по тому же варианту. Результат — `window.SiteVehicle = { kind, V }`.
- Кадры: набор фуры — `src/assets/ride/`. Если появится `src/assets/ride-bus/{hd,land,port}` (те же имена
  001–120.webp), `build.js` добавит `data-frames-bus` и для автобуса пойдёт он; пока его нет — сборка пишет
  предупреждение, для автобуса показывается фура и пометка `busSoon` (стеклянная плашка вверху).
  Сейчас набор автобуса есть (из `video/bus.mp4`), пометка не показывается. «Оба» — кадры фуры.

## «Дорога»: ролик с карточками (`src/ride.js`, секция `.ride`)

- ОТМЕНЕНО прежнее решение «карточки шагов поверх видео убраны»: теперь владелец хочет всю информацию порциями
  поверх едущей машины. 10 карточек по очереди: 0 — вступление (единственный `h1`, текст прямо на сцене,
  без карточки) → 1–5 — пять шагов со счётчиком «N из 5» → 6–8 — «Профессия» → 9 — финальная карточка.
- Пороги карточек — доли прокрутки секции: `AT = [0, .08, .18, .28, .38, .48, .58, .67, .76, .87]` в `ride.js`.
  Счётчик (кольцо) виден только на шагах и показывает номер шага.
- Высота секции — переменная `--ride-vh: 900vh` в `landing.css` (~90vh на карточку), она задаёт скорость ролика.
  Ограничитель скорости по времени пробовали — даёт рассинхрон, не возвращать.
- Автостарт: при открытии машина сама проезжает от 0 до `AUTO_TO = 6 / 119` (~5%, ровно 7-й кадр — в покое целый
  кадр, без смешивания двух) за `AUTO_MS = 3200` мс (ease-out). Стартует, только когда загружены первые `FIRST = 9`
  кадров подряд (они грузятся первыми; не дольше 4 с ожидания) — без рывков,
  дальше — прокрутка (положение ролика = auto + прокрутка × (1 − AUTO_TO)). `AUTO_MS = 0` — выключить.
  Без автостарта при `prefers-reduced-motion` и Save-Data.
- Движок: секция «прилипает» (sticky), кадр выбирается по прокрутке и рисуется на `<canvas>` как cover,
  соседние кадры смешиваются (без ступенек), через `SNAP_DELAY = 120` мс после остановки прокрутки сцена доезжает
  до целого кадра (в покое нет двоения) — до СЛЕДУЮЩЕГО по ходу движения, не до ближайшего, и держит его (`hold`),
  пока листают в ту же сторону: фура никогда не откатывается назад (решение владельца), кадры декодируются заранее (`img.decode()`), грузятся «от грубого
  к точному» (первые `FIRST` подряд, затем каждый 8-й, 4-й, 2-й, все). Первый кадр — заглушка (`<picture class="ride__still">`)
  и предзагрузка: скрипт в `<head>` сам ставит `preload` нужной машины (выбран автобус и его кадры есть — `ride-bus`)
  и нужного размера (land 1280 или hd 1920 через `imagesrcset` — на больших и Retina-экранах чёткий, телефон — port),
  скрипт после `<picture>` меняет заглушку на автобус. Фон финала для автобуса меняет `vehicle.js`.
- Наборы: `hd` 1920×1086 (широкие и Retina), `land` 1280×724, `port` 720×1274 (экран уже 9:10, из вертикального
  ролика `video/vertical.mp4`; кадр обрезается по высоте с привязкой 80% — `ay` в `SETS`, так же
  `object-position` постера: машина внизу, режется небо).
- ПК: карточки слева внизу (до 540px, стекло), кольцо 120px справа внизу, затемнение сверху и слева.
  Телефон (`max-aspect-ratio: 9/10`): кадр 9:16 на весь экран, машина в нижней трети — карточки СВЕРХУ под шапкой,
  над небом, не выше ~38% экрана; вступление тоже сверху на тёмном градиенте; кольцо — значок 44px в правом
  верхнем углу карточки. Проверено скриншотами 360×740, 390×844, 430×932, 768×1024: карточки не заходят на машину.
- Навигация: одна большая прозрачная кнопка «Далее» (`jNext`, `#ride-next`) — на ПК по центру внизу (карточки
  и кольцо подняты над ней, `bottom: 128px`), на телефоне по центру экрана (52%; планшет в портрете от 600px — 42%) — между карточкой и машиной.
  `goTo()` в `ride.js` своей анимацией (не `behavior: 'smooth'`) докручивает до начала следующей карточки, ролик
  за это время проезжает свой отрезок; длительность `GO_MS = [1800, 3200]` мс (владелец попросил в 2 раза медленнее
  первой версии); колесо, касание или клавиша останавливают анимацию; с последней карточки — к плану (фокус на его
  заголовок). Доступное имя кнопки называет, куда ведёт («Далее: Learner permit»). Справа шкала из 10 точек
  (`.dots`, для мыши, `aria-hidden`; клик — тот же переход).
  Пробовали и убрали по просьбе владельца (не возвращать): «Далее» внутри каждой карточки, плавающую кнопку
  «Собрать план» на ПК, усиленное затемнение и перестановку кнопок первого экрана.
- Доступность: текст всех карточек всегда в DOM упорядоченным списком, неактивные — `aria-hidden` + `inert`,
  у секции `aria-label`.
- `prefers-reduced-motion`: ролик всё равно идёт за прокруткой (решение владельца: он сам не играет), но без
  инерции, карточки сменяются мгновенно, без автостарта и звука. Save-Data (`navigator.connection.saveData`)
  и без JS — статичная версия: один кадр (`<img alt=jStillAlt>`) и карточки обычным списком.
- Нарезка кадров (ffmpeg), пример для hd: `ffmpeg -i video.mp4 -frames:v 120 -vf "fps=12,scale=1920:-2:flags=lanczos" -c:v libwebp -quality 56 src/assets/ride/hd/%03d.webp`.
  Без фильтра резкости: он усиливает мерцание ИИ-текстур. Если ffmpeg собран без libwebp (как из brew),
  нарезать в PNG и перевести `cwebp -q 56`. Для land: `scale=1280:-2`, для port (из вертикального ролика): `scale=720:-2`.
  Автобус: hd и land — те же команды из `video/bus.mp4` в `src/assets/ride-bus/{hd,land}/`. Вертикального ролика
  автобуса нет, поэтому port делает `python3 assets-src/ride-bus/make-port.py`: окно 9:16 ведёт автобус по замеру
  `assets-src/ride-bus/track.txt` и плавно приближает его (низ автобуса всегда на 88% высоты кадра, верх — не выше 58%),
  кадры 720×1280. В первые ~2 с автобус в кадре широкий, на узких телефонах его концы чуть обрезаны.

## Звук главной (`src/shared/sound.js`)

- Кнопка звука в шапке — общий `window.SiteSound` (`localStorage.sound`, по умолчанию off). Аудиоконтекст —
  только по жесту: кнопка, а если звук был включён раньше — первый клик или клавиша на странице.
- Фоновая петля `src/assets/media/ambient.m4a` (подключается, только если файл есть): ветер/гул из звуковой дорожки
  `video/vertical.mp4`. Дорожка к концу затухает, поэтому взяты 0,3–6,3 с, громкость выровнена, конец сведён
  с началом (0,6 с) — файл бесшовный и играет одним источником с `loop = true` (тихие края кодека отрезаются).
  Команды (повторить при новом ролике):
  `ffmpeg -i video/vertical.mp4 -vn -af "highpass=f=30,dynaudnorm=f=200:g=15:m=20" -ar 48000 full.wav`,
  `ffmpeg -ss 0.3 -t 6 -i full.wav seg.wav`, затем начало (0–0,6 с, `afade=in`) смешать с концом (5,4–6 с,
  `afade=out`) через `amix` и приклеить середину (0,6–5,4 с) через `concat`, громкость до ~−20 LUFS (`volume`),
  кодировать `-c:a aac -b:a 96k`.
- Пока звук включён: скорость прокрутки → speed += (min(1, px/с ÷ 2500) − speed) × 0.08; громкость 0.35 + speed × 0.55;
  скорость воспроизведения 1 + speed × 0.12. На скрытой вкладке — пауза. При `prefers-reduced-motion` и Save-Data
  звука нет.

## Экран выбора транспорта (`/<язык>/choose/`)

- Входная страница сайта: «Выберите категорию», фура слева (C), автобус справа (D). Адреса `/pl/choose/`,
  `/pt/choose/`, `/ru/choose/`, `/en/choose/`; язык по умолчанию — английский.
- Сборка: `src/choose/index.html` — шаблон с ключами `{{…}}` из `src/locales.js` (ключи `choose*`, `sound*`,
  а также `langLabel`, `langName`, `call`, `waHello`) и общими блоками `{{icons}}`, `{{header}}`, `{{dock}}`;
  `build.js` собирает его для каждого языка. Свои файлы — один раз в `dist/choose-assets/`: `choose.css` (сцена,
  заголовок, подписи), `choose.js` (сцена, выбор, своя кнопка звука и подсказка), `img/`, `media/`.
  Общие с главной (`shared/tokens.css`, `shared/hud.css`, `shared/hud.js`, `shared/sound.js`) — в `dist/shared/`.
- Корень `dist/index.html`: язык из `localStorage.lang` → если `DETECT_BROWSER_LANGUAGE = true` (в `build.js`,
  сейчас `false`) — язык браузера → иначе `/en/choose/`. Строка запроса сохраняется.
- После выбора: `localStorage.vehicle` = `truck` | `bus` и переход на главную `/<язык>/?vehicle=…`.
  Вернувшийся посетитель (машина уже в `localStorage`) с корня сайта попадает сразу на главную; экран выбора открывается
  кнопкой категории в шапке.
- Подгрузка главной (`src/choose/preload-home.js`): после полной загрузки экрана выбора, в свободное время браузера —
  `prefetch` HTML главной и первые 9 кадров + каждый 8-й обоих роликов в наборе под этот экран (hd / land / port,
  как `pickSet` в `ride.js`); по клику на машину — в первую очередь её кадры. При Save-Data ничего не грузит.
  Ссылки «Пока не знаю» на экране выбора нет (убрана по просьбе владельца; нижняя граница ряда подписей осталась
  прежней — 92% / 81%). Если `?vehicle=` уже в адресе экрана выбора — сразу на главную.
- Шапка — общая (см. «Шапка»): логотип, язык, кнопка звука, WhatsApp (`waHello`); без кнопки категории.
  На телефоне: только значок, код языка и круглая кнопка звука; WhatsApp и звонок — в нижней панели `.dock`.
- Ключи localStorage (общие для всего сайта): `lang` (pl|pt|ru|en), `vehicle` (truck|bus), `sound` (on|off,
  по умолчанию off — читать через `window.SiteSound` из `shared/sound.js`), `soundTipSeen` (подсказку «включите звук»
  на экране выбора показали один раз: ПК ~6 с пузырём под кнопкой, телефон 4 с плашкой над нижней панелью).
- Звук: аудиоконтекст создаётся только по жесту (кнопка звука или выбор машины). Мотор играет при выборе,
  только если звук включён и нет `prefers-reduced-motion`; при наведении — никогда.
  Файлы: `src/choose/media/engine-truck.mp3` и `engine-bus.mp3` — `build.js` подключает только существующие.
- Заголовок: подсказка (золото, капс) + заголовок Oswald. ПК — начинается около 18% высоты; телефон — 84px от верха,
  подсказка под заголовком. `choose.js` держит не меньше 24px от шапки и от машин (поднимает блок, затем уменьшает шрифт).
- Подписи машин — один ряд на высоте `--labels-y` (считает `choose.js`: ниже машин, ПК ~85%, телефон ~72%),
  каждая по центру под своей машиной (`--x`). На ПК в одну строку «название · категория», на телефоне в две.
- Выбор: вторая машина исчезает (слой «только выбранная, фары горят»), заголовок и шапка не гаснут;
  через 1,6 с затемнение и переход.
- Пять слоёв одного кадра (одинаковые размер и кадрирование, переключение — прозрачностью ~400 мс):
  `choose-both` (обе машины), `choose-truck`, `choose-bus` (одна машина), `choose-truck-lit`, `choose-bus-lit` (фары горят).
  Каждая в двух ширинах: `-1600.webp` и `-2720.webp` (2720 — ширина исходника, больше не растягиваем).
- Исходники лежат в `assets-src/choose/` (оригиналы ИИ — без суффикса). Слои собирает скрипт
  `bash assets-src/choose/build-layers.sh` (ImageMagick): пишет `*-updated.png` рядом с оригиналами и WebP
  в `src/choose/img/`. Что он делает:
  1) все слои — из ОДНОГО кадра `intro-photo.png` (ИИ перерисовывает мелкую текстуру на каждом фото, и при смене
     слоёв кадр «кипел»): в слоях «только фура/автобус» заменена лишь область убранной машины с тенью,
     в слоях с фарами добавлены только фары и свет на дороге;
  2) обработка дороги против «мазков» ИИ-увеличения (медианный фильтр + зерно) ВЫКЛЮЧЕНА: на экране выглядело
     замыленно и дёшево — владелец попросил вернуть. Включается `ROAD_FIX=1` только для экспериментов.
     Убрать мазки по-настоящему можно только новым рендером/апскейлом без артефактов, не фильтрами.
  Вне зон машин все слои совпадают до пикселя.
  Поменяли фото — поправьте в скрипте области (`box`, `lit`, контур дороги, рамки машин) и запустите заново.
- Смена слоёв без мерцания: нижний слой `choose-both` всегда непрозрачный, новый слой проявляется ПОВЕРХ текущего,
  и только потом слои под ним мгновенно прячутся (`showScene` в `choose.js`). Наверх поднимается только полностью
  скрытый слой; если слой ещё виден (быстро вернулись «туда-обратно»), вместо подъёма плавно гаснут слои над ним —
  иначе он резко выскакивает поверх. Не делать встречное затухание двух
  слоёв: в середине оба полупрозрачные и кадр темнеет.
- Наведение и клик — только по рамкам машин: `boxes` в `SETS` в `choose.js` ([лево, верх, право, низ] в долях
  кадра, с зеркалами и колёсами). Кнопки `.zone` ставятся ровно над машинами (`placeZones`) по кадрированию слоёв
  `pos` (ПК 0.53 / 0.6, телефон 0.49 / 0.57 — не трогать, сцена выверена). Промежуток между машинами замерен:
  `SPLIT = 0.533` (ПК), `SPLIT_MOBILE = 0.538` (телефон) — рамки обрезаются по нему, зоны не перекрываются.
  Мимо машин (небо, дорога) — общий кадр. Против мигания: рамку показанной машины расширяем на `HYST`,
  уход из рамки — с задержкой `SWITCH_DELAY` (150 мс). Поменяли фото — перемерьте `boxes` и `SPLIT*`.
- Телефон в портрете (`max-aspect-ratio: 4/5`): та же сцена и та же механика, но вертикальный набор кадров
  `choose-v-*` (1536×2720, WebP 1080 и 1536): машины рядом, сверху небо под заголовок. Наборы описаны в `SETS`
  в `choose.js` (размер кадра, кадрирование `pos`, рамки `boxes`); нижний слой выбирает браузер через `<picture>`,
  остальные слои `choose.js` грузит из `data-h` / `data-v`. Поворот телефона переключает набор на лету.
  Наведения на телефоне нет: нажатие на машину сразу запускает сценарий.
- Вертикальные исходники: `intro-mobile-photo.png` (общий кадр 832×1472), `intro-mobile-only-truck.png`,
  `intro-mobile-only-bus.png`, `intro-mobile-truck-light.png`, `intro-mobile-bus-light.png` (1536×2720).
  Как на ПК, все слои строятся от ОДНОГО цельного кадра — `intro-mobile-photo.png` (увеличен и подогнан масштабом
  и сдвигом): в нём правильная тень автобуса и чистые края машин. Склейки из разных кадров давали светлые полосы
  и «криво вырезанный» автобус — не возвращать. В «только фуре» заменена лишь область автобуса и его тени,
  в «только автобусе» — лишь область фуры, взятая из `intro-mobile-only-bus.png` как есть (с тенью
  нейросети, как на ПК). Заплатки дороги на месте фуры выглядели искажённо — не возвращать; если тень мешает,
  перегенерировать `intro-mobile-only-bus.png`. Фары — прибавка света из кадров
  с горящими фарами. Общий кадр мягче остальных: если появится `intro-mobile-photo.png` в 1536×2720, станет резче.
- На главной `vehicle.js` подставляет выбранную категорию — см. «Транспорт».
